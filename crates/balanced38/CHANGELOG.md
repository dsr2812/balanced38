# Changelog

All notable changes to the balanced38 crate. The ledger is part of the
shipment: nothing here is claimed that the Lean certificate and the
differential oracle do not also claim.

## [1.2.1] — 2026-11-06

The front-door patch. **No arithmetic or API changes.**

- **Repository link** — the public mirror is now declared in Cargo.toml:
  `https://github.com/dsr2812/balanced38`.
- **README** — a short “What this is not” section: not a refinement
  proof, not a general big-integer library, not a base64-style encoder.

## [1.2.0] — 2026-11-04

The honest-front-door release. The arithmetic contract is unchanged; the
surface is additive and the signed-i128 refusal contract is now proved.

- **`Ord` / `PartialOrd` for `Balanced38`** — the lane's own order,
  computed by the proven subtraction (the sign of `self − other`); no
  fold to `i128`, so the shore does not bound the comparison.
- **`Default` for `Rational38`** (the Void).
- **The signed-i128 refusal contract** — `verify/Balanced38/Shore.lean`
  proves `checkedToI128` (`some` iff in range), `checkedMul`
  (zero-absorbing; refuses out-of-shore operands/product), and
  `checkedDivRem` (zero divisor, `MIN / −1`, out-of-shore operands),
  including `i128::MIN`. Certificate total: **177 theorems** (159 core +
  18 shore), **3,340 lines**, 0 sorries.
- **Right Door wording** — the Lean certificate proves the mathematical
  lane and its shore contract; the Rust implementation is tested against
  them, not refinement-proved. README, crate docs, and the theorem ledger
  now say this plainly. The public docs use engineering wording only;
  no private links. Two certificate theorem names are neutralised
  (`triad_reading_closed` → `direct_reading_closed`,
  `emergence_reading_closed` → `conjugate_reading_closed`); the
  statements, count, and line count do not change.
- **Boundary fixes** — divisor `i128::MIN` no longer panics in debug;
  `checked_pow` returns `None` instead of panicking; `from_dense_digits`
  validates bytes and canonicalises gaps; `to_i128` wraps explicitly in
  both profiles; `checked_mul` refuses an operand beyond 25 places before
  the grid; `Rational38` reads the denominator sign through the checked
  door. `verify/verify_all.sh` runs Lean + Rust (debug + release).
- Lint armor: `#![forbid(unsafe_code)]` + `#![warn(missing_docs)]`
  (docs made complete: `is_zero` and `desk_form`).
- Rustfmt pass; README badges; a License section.

## [1.1.0] — 2026-09-17

The promise's store: `Rational38`.

- **Rational38**: the exact fraction, `num / den`, ALWAYS reduced and
  `den > 0`, the sign on the numerator, the Void the only zero. Built
  on the proven lane. `from_ints` (refuses a zero denominator, flips
  the sign onto the numerator, reduces via the lane's own Euclidean
  gcd — reduction only shrinks, so the inputs' shore is preserved).
- **The checked family**: `checked_add/sub/mul/div/cmp` — every
  composition rides the lane's checked products and refuses loudly
  (`None`) one step past the i128 shore. Never a wrapped lie; the
  shore law is pre-registered in the module docs.
- The Lean core certificate (**159 theorems, 0 sorries**, 3,284 lines
  including the smoke test) is unchanged in this release. The 18-theorem
  signed-i128 refusal contract (`verify/Balanced38/Shore.lean`) arrives
  in 1.2.0.

## [1.0.0] — 2026-09-16

The lane, complete and hand-overable.

- **The lane**: every i128 has exactly one membrane form; add, sub, mul,
  div-rem, neg, canonical fold, the O(n) fast walk `from_i128_fast`.
  Every refusal loud, never a wrapped lie.
- **The certificate ships inside the crate**: `verify/` carries the Lean
  4.33.1 proof (core-only, `import Init`, no Mathlib, 0 sorries) and
  `verify.sh` reproduces it in one command.
- **The oracle ships inside the crate**: `tests/` carries a 3145-line
  differential corpus generated by an independent arbitrary-precision
  Python engine, and the suite that swears against it.
- Exhaustive unit coverage against the hardware oracle (native i128),
  sweeping the membrane at 19/20 boundary and every carry point.
